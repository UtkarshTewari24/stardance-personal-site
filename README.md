# Alex Rivera Personal Site

A bright, responsive one-page personal site built with vanilla HTML and CSS for the Hack Club Stardance Personal Site mission.

## What’s included

- Accessible skip link and semantic sections
- Responsive layout for phones, tablets, and desktops
- About, Projects, and Contact sections
- Clear `TODO` markers for replacing placeholder content
- No build step or dependencies

## Run locally

Because this is a static site, you can open `index.html` directly in a browser. For a local server, run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

1. Replace the name, biography, email, and social links in `index.html`.
2. Replace the three sample project cards with your own work.
3. Adjust the colors and spacing in `styles.css` if you want a personal twist.
